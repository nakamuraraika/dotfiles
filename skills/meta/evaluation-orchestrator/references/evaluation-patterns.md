# Evaluation Patterns

Choose topology by failure risk. Do not add agents merely for theatrical variety.

## Triangulated reconstruction

Use when a target is complex enough that one framing could dominate later judgment.

```text
source -> adversary
       -> advocate
       -> blind explorer
       -> integration -> epistemic audit
```

Properties:
- adversary and advocate read the primary source directly and use normalized IR only as an index;
- blind explorer receives no seeded concerns or upstream interpretation;
- integration preserves dissent and blind-only discoveries.

## Decision-centered IR

Use when the evaluation concerns design or policy decisions. Keep observation, rationale, invariants, attack, defense, verification, and alternatives in one record. This prevents a critique from becoming detached from the decision and evidence it concerns.

## Case-first compilation

Create cases and expected traces before final evaluator instructions. Use when output-format constraints could cause shallow box filling or when false-positive and false-negative behavior matters.

## Blinded judgment

Hide evaluator self-grades and improvement proposals from the judge. Use holdout expectations to detect criterion leakage and overfitting.

## Earliest-responsible-stage repair

When a run fails, localize the first stage that introduced the defect. Repair source reconstruction before prompt wording, and repair case design before scoring rhetoric.

## Slow promotion ladder

Promote learning through:

`provisional note -> experimental patch -> target-specific rule -> cross-target pattern -> core invariant`

A single successful repair is not evidence for a universal rule.

## Evidence-backed simplification

Roles may be merged only after replay shows no material loss in:
- independent discovery;
- source fidelity;
- dissent preservation;
- issue recall;
- false-positive control.
