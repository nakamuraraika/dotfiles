# Learning Across Runs

This skill evaluates targets; it does not generate skills.

Learning is limited to improving future evaluation execution through reusable observations such as:

- recurring failure patterns;
- high-information questions;
- useful evidence sources;
- domain-specific evaluation lenses;
- misleading heuristics;
- effective verification methods.

For each candidate lesson, record:

- observation;
- evidence and source runs;
- applicable context;
- non-applicable context;
- confidence;
- effect on future evaluation behavior.

Do not promote one-off opinions to general rules. Do not mutate the skill automatically. Changes to the skill require an explicit separate request and review.
