# Fast Feedback Loop

## First loop

Produce the earliest defensible evaluation snapshot:

- provisional verdict;
- top strengths;
- top one to three risks;
- most valuable unknown;
- smallest next action.

Do not wait for exhaustive analysis before exposing a decisive uncertainty.

## Subsequent loops

1. ingest changes and feedback;
2. map each change to IR elements and finding IDs;
3. identify affected lenses and dependencies;
4. reassess affected findings;
5. run focused regression checks;
6. update verdict, confidence, and conditions;
7. preserve superseded findings and rationale;
8. summarize what changed in understanding, not only in wording.

## Convergence signals

- no unresolved critical findings;
- high findings have owners and acceptance conditions;
- new evidence changes only local findings;
- reviewers no longer discover new decision-relevant concern classes;
- remaining disagreements are explicit trade-offs or accepted risks.
