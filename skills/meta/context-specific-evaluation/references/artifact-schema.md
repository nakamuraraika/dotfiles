# Artifact Schema

Recommended workspace:

```text
evaluation/
├── 00-brief.md
├── 01-evidence-map.md
├── 02-evaluation-ir.md
├── 03-supporting-review.md
├── 04-adversarial-review.md
├── 05-coverage-review.md
├── 06-alternatives.md
├── 07-findings.md
├── 08-report.md
├── 09-change-log.md
└── evidence/
```

Stable IDs:

- requirements: `REQ-###`
- assumptions: `ASM-###`
- evidence: `EVD-###`
- decisions: `DEC-###`
- findings: `FND-###`
- questions: `QST-###`

A finding should link to at least one goal, requirement, decision, assumption, or evidence entry.
